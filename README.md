# Nagashima Villa 11 公式サイト＋自社予約システム

GitHub Pagesの公式サイトに、Googleスプレッドシート・Googleカレンダー・Airbnb iCal・Stripeを使った自社予約フォームを組み込んだ版です。

## 今回追加した機能

- 公式サイト内に予約フォームを埋め込み
- チェックイン・チェックアウト・泊数・人数の入力
- 5名まで1泊30,000円
- 金・土・日曜日は基本料金を20％加算
- 6人目以降は子どもを含め、1名1泊3,000円を加算
- 1予約につき清掃費3,000円
- 最大11名、最低1泊、当日12:00まで受付
- 大型連休・オンシーズン・年末年始等の日別料金上書き
- Airbnb iCalと自社予約カレンダーによる空室確認
- Stripe決済完了後の予約確定
- 20分間の仮押さえと期限切れの自動解除
- お客様・管理者への予約確定メール
- 日本語・英語対応

詳しい導入方法は `SETUP-GUIDE.md` を参照してください。

## 公開前に行うこと

1. `images` フォルダへ写真を配置します。
2. 下表のファイル名に合わせると、HTMLを修正せず差し替えできます。
3. GitHubリポジトリのルートへ本フォルダ内のファイルを置き、GitHub Pagesを有効にします。
4. カスタムドメイン利用時は、リポジトリ設定で `nagashimavilla11.com` を登録します。

| ファイル名 | 推奨写真 |
| --- | --- |
| `living-room.webp` | リビング全景・トップ画像（DSC02467） |
| `kitchen-wide.webp` | キッチン全景（DSC02454） |
| `tatami-room.webp` | 床の間を含む和室（DSC02401） |
| `bedroom-triple.webp` | 3台のベッドを配置した寝室（DSC02413） |
| `bedroom-twin.webp` | ツインルーム（DSC02427） |
| `washroom.webp` | 洗面・ランドリー（DSC02387） |
| `bathroom.webp` | 浴室（DSC02397） |
| `kitchen-appliances.webp` | 冷蔵庫・電子レンジ・食器類（DSC02461） |

推奨形式はJPEGまたはWebP、長辺2000px前後、1枚500KB程度以下です。ファイル名は半角英数字にします。
